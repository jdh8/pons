# Binky Points with error bars — N-S double-dummy tricks in their best suit

A hand's valuation is the sum of its four holdings' entries. A partnership sums both hands. Then

```
mu     = 8.426 + sum of the 8 mu entries        (tricks)
sigma2 = 0.990 + sum of the 8 var entries       (trick^2)
P(T >= k) = Phi((mu - k + 0.5) / sqrt(sigma2))
```

The label is N-S double-dummy tricks in their best suit. Weights are **excess versus an average holding**: the fit is rank-deficient by two directions (`sum n = 8` and `sum n*size = 26`), so the table is only defined up to `w_c -> w_c + a + b*size(c)` with `8a + 26b = 0`, and it is pinned here by `sum p_c w_c = 0` and `sum p_c size(c) w_c = 0`.
